Listing Contents with ls

Start from your home directory: cd on its own always takes you home, and pwd prints where you are. Then ls shows what is inside.

Reading the output
  • pwd prints the full path of the working directory; the first slash is the root directory (e.g. /home/sysadmin).
  • ls lists the contents of the current directory, in alphabetical order by default.
  • Many distros colour the names: white = standard file, blue = directory, cyan = symbolic link, green = executable, red = archive.
What do you want to do?Sample command
List the current directoryls
List a directory using a relative pathls Documents/School
List a directory using an absolute pathls /usr
List several directories at oncels /usr ~ Documents — names separated by spaces
Exam tip: Know the three starter commands — pwd (where am I?), cd (move), ls (what is here?).
සිංහල පරිවර්තනය

pwd මගින් ඔබ සිටින directory එකේ සම්පූර්ණ මාර්ගය පෙන්වයි; පළමු slash එක root directory එක දක්වයි. ls මගින් වත්මන් directory එකේ ඇති දේ පෙරනිමියෙන් අකාරාදී පිළිවෙලට පෙන්වයි. ls Documents/School (relative), ls /usr (absolute) වැනි මාර්ග දුන් විට ඒ directory පෙන්වයි; කිහිපයක් space එකකින් වෙන් කර දිය හැක (ls /usr ~ Documents). වර්ණ: සුදු = සාමාන්‍ය file, නිල් = directory, cyan = symbolic link, කොළ = executable, රතු = archive.

2

Hidden Files

Some entries are not shown by plain ls. In Linux, any name that starts with a dot (full stop) is hidden.

Hidden (dot) files
  • Examples: .bashrc, .profile, .bash_history, .bash_logout.
  • Show them with ls -a (long form ls --all) or ls -la for the detailed view.
  • Some rarely-used system files are hidden to reduce clutter — leave them alone unless you know what you are doing.
GUI equivalent: in the file manager, open the menu (three bars) and choose Show hidden files to see the same dot-files.
සිංහල පරිවර්තනය

නමක් තිතකින් (.) ආරම්භ වුවහොත් එය සැඟවුණු (hidden) file එකකි, උදා: .bashrc, .profile, .bash_history. ls -a හෝ ls -la මගින් ඒවා දැකිය හැක. සමහර පද්ධති file අවුල් අඩු කිරීමට සඟවා ඇත; ඒවා අනවශ්‍යව වෙනස් නොකරන්න. GUI එකේදී මෙනුවෙන් Show hidden files තෝරන්න.

3

Command Options

Options (also called flags) change how a command behaves. Short options use one hyphen; long options use two. Arguments say where to look; options say how to display.

What do you want?CommandNotes
Hidden filesls -a · ls --allShort and long form are identical
Hidden + long, combinedls -a -l · ls -al · ls -laAll identical — letter order does not matter
Long listingls -l /var/logPermissions, owner, size, timestamp, name
Reverse orderls -lr Documents · ls -rl DocumentsOrder of options is immaterial
Date orderls -lt /etcNewest first
Size orderls -lS /var/logUppercase S
Human readablels -lh DocumentsSizes in K rather than bytes
Include sub-directoriesls -lR ~Uppercase R = recursive (not -r = reverse)
Remember
  • Full-word options use two hyphens; shorthand uses one and can be stacked: -al = -la = -a -l.
  • -r (reverse) and -R (recursive) are different options.
  • ls -l line: d or -, permissions, links, owner, group, size, timestamp, name.
සිංහල පරිවර්තනය

Options යනු විධානයක හැසිරීම වෙනස් කරන අමතර අකුරු ය. කෙටි ආකාරය එක් හයිෆනයකින් (-a), දිගු ආකාරය හයිෆන් දෙකකින් (--all). -l විස්තරාත්මක ලැයිස්තුවක් දෙයි; -r ප්‍රතිලෝම, -t දිනය අනුව, -S ප්‍රමාණය අනුව, -h කියවීමට පහසු ප්‍රමාණ, -R උප-directories ද (recursive). Options වල අනුපිළිවෙල වැදගත් නැත.

Changing Directories with cd

cd changes directory to the one given by the path. Where the path starts decides whether it is absolute or relative.

Move to…Sample commandType of path
Nested directory, relativecd School/ArtRelative — no leading / or ~
Nested directory from rootcd /home/sysadmin/Documents/SchoolAbsolute from root
Nested directory from homecd ~/Documents/School/MathAbsolute from home
Root directorycd /—
Home directorycd ~ · cd—
Up one levelcd ..—
Up two levelscd ../..—
Key points
  • No output means the move succeeded — check the prompt to see the current directory.
  • An error appears if the directory does not exist.
  • Use pwd any time to confirm where you are.
සිංහල පරිවර්තනය

cd යනු directory වෙනස් කරන විධානයයි. / න් ආරම්භ වන මාර්ගය root සිට (absolute); ~ න් ආරම්භ වන මාර්ගය home සිට; වෙනත් ඕනෑම මාර්ගයක් දැනට සිටින directory එකට සාපේක්ෂ (relative). cd .. එක් මට්ටමක් ඉහළට, cd ../.. මට්ටම් දෙකක් ඉහළට. සාර්ථක නම් කිසිවක් print නොවේ — prompt එක බලන්න.

Case Sensitivity & the Manual

Linux treats upper and lower case as different — for commands, options and names. When unsure, read the manual.

Two habits to build
  • -l and -L are different options; Downloads and downloads are different names.
  • man ls opens the manual page for ls with every option; press q to quit.
Exam tip: “Command not found” or “No such file or directory” is very often a capital-letter mistake.
සිංහල පරිවර්තනය

Linux හි case-sensitive ය: -l සහ -L වෙනස් ය; Downloads සහ downloads ද වෙනස් ය. cd documents අසාර්ථක වන අතර cd Documents සාර්ථක වේ. විධානයක සවිස්තරාත්මක උපකාරය සඳහා man ls භාවිත කරන්න; man පිටුවෙන් ඉවත් වීමට q ඔබන්න.

Tab Completion & the touch Trap

Press Tab to let the shell finish a name for you — faster typing and fewer typos.

You typeMatchesResult
cd De + TabOnly DesktopCompletes to Desktop/
cd D + TabDesktop, Documents, DownloadsNothing happens
cd D + Tab TabSame threeLists all the options
cd Dow + Tab (Download & Downloads exist)Share the prefix DownloadFills up to the shared part, then stops
Summary: a single Tab fills in as far as it is certain; a double Tab shows the remaining choices. Type one more character to narrow it down.
Why it matters: the touch trap
touch with a typo creates a new file
  • Set-up from the video: mkdir Download (capital D) so Download and Downloads now sit side by side — ls confirms it.
  • touch Download (using Tab) on a name that exists only updates its timestamp.
  • touch download (lowercase d) names something that does not exist, so it creates a new empty file — and prints no error.
  • Check with ls -l: Download (directory) has the newer timestamp and a new download file appears.
  • Clean up: rm download removes the file; rm Download fails because it is a directory; rm -r Download removes it.
CommandName exists?Result
mkdir Download—Creates a directory with a capital D, beside Downloads
touch Download (via Tab)Yes — a directoryTimestamp updated, nothing else changes
touch download (typo)NoNew empty file created, no error
rm downloadYes — a fileFile removed
rm DownloadYes — a directoryError: Is a directory
rm -r DownloadYes — a directoryDirectory and contents removed
Rule of thumb: use Tab for every name you did not just create. The most common unnoticed mistake is capitalisation. Be careful with rm -r — there is no recycle bin.
සිංහල පරිවර්තනය

Tab යතුර නම ස්වයංක්‍රීයව සම්පූර්ණ කරයි. ගැළපෙන්නේ එක් නමක් පමණක් නම් එය සම්පූර්ණ වේ (cd De → Desktop/). නම් කිහිපයක් ගැළපේ නම් පළමු Tab එකෙන් කිසිවක් නොවේ; Tab දෙවරක් ඔබා ගැළපෙන සියල්ල ලැයිස්තුගත කරන්න. තවත් අකුරක් ටයිප් කර තෝරන්න. touch උගුල: පවතින නමකට touch කළොත් timestamp එක පමණක් යාවත්කාලීන වේ; නමේ අකුරු වැරදුණොත් (උදා: downloads) අලුත් හිස් file එකක් හැදේ, error එකක් නොපෙන්වයි. Tab භාවිත කළොත් නම පවතින බව තහවුරු වේ. file මකන්න rm, directory මකන්න rm -r.

    What to Remember for the Exam

    The exact facts this lesson loves to test — memorize these cold.

    • pwd prints the full path; the first / is the root directory.
    • pwd prints the current directory; cd alone returns to the home directory.
    • ls hides dot-files; ls -a / --all shows them. ls -l gives the long format.
    • -al = -la = -a -l; one hyphen for short options, two for long. -r reverse, -t time, -S size, -h human-readable, -R recursive.
    • Path starting with / = absolute from root; ~ = absolute from home; anything else = relative. cd .. up one, cd ../.. up two, no output = success.
    • Linux is case-sensitive: -l ≠ -L, Downloads ≠ downloads.
    • man ls shows the manual; press q to exit.
    • touch on an existing name updates its timestamp; on a mistyped name it creates a new empty file. rm removes files; rm -r removes directories.
    • Tab = complete as far as unambiguous; Tab Tab = list candidates.
